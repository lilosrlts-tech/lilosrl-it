LILO — ISTRUZIONI SEMPLICI
==========================

CARTELLA PROGETTO (nuovo sito):
  C:\Users\info\Progetti\lilosrl-it

SE NON VEDI NULLA NEL BROWSER, SEGUI QUESTI 3 PASSI:

PASSO 1 — CHIUDI TUTTO
  Doppio clic su:  FERMA_LILO.bat
  (chiudi anche eventuali finestre nere aperte)

PASSO 2 — RIAVVIA
  Doppio clic su:  AVVIA_LILO.bat
  ATTENDI fino a vedere "Sito pronto!" (può richiedere 30 secondi)

PASSO 3 — VERIFICA
  Doppio clic su:  VERIFICA_LILO.bat
  Deve comparire "OK" su tutte le righe verdi.

LINK DA USARE (copia nel browser):
  Sito pubblico:     https://www.lilosrl.it
  Admin flotta:      https://lilosrl-admin.vercel.app/admin/login
  Admin (locale):    http://localhost:3001/admin/login
  Password admin online: vedi messaggio Cursor / Vercel env ADMIN_PASSWORD
  Password admin locale: vedi admin/.env.local → ADMIN_PASSWORD

IMPORTANTE:
  - Sito pubblico: usa www.lilosrl.it (non solo localhost)
  - Admin online: stesso Supabase del sito (nessun progetto DB extra)
  - In locale: AVVIA_LILO.bat → localhost:3000 + :3001
  - La prima apertura è lenta (20-30 sec): è normale
  - Se la pagina è bianca: premi Ctrl+F5
  - Non chiudere le finestre nere mentre usi i server locali

Se VERIFICA_LILO mostra errori rossi, scrivi cosa dice e ti aiuto.
