------------------

  seo_keywords    TEXT[]

    slug (univoco), pubblicato, attivo, in_evidenza, ordine

  Contenuto:

  SEO:

    twitter_description

  IA / dati strutturati:

  Specifiche furgoni:
    portata_kg, volume_carico_mc, volume_metri_cubi, portata_utile_kg,
    trazione, passo, tetto, sensori_parcheggio,
    lunghezza_mm, larghezza_mm, altezza_mm,
    vano_lunghezza_mm, vano_larghezza_mm, vano_altezza_mm,

3. CARICAMENTO IMMAGINI — FLUSSO E CODICE
================================================================================

Il upload è distribuito su 4 livelli:

  VeicoloForm (selezione file)
      ↓ onSubmit con { copertina, secondaria }
  AdminPanel.uploadPhotos()
      ↓ POST multipart /api/veicoli/{id}/foto
  route.ts (API)
      ↓ uploadVeicoloFoto()
  Supabase Storage (bucket veicoli) + INSERT in tabella foto


A) UI — admin/src/components/admin/VeicoloForm.tsx
---------------------------------------------------
Due input file con anteprima locale:

  - Foto copertina (3/4 frontale): input type="file" accept="image/*"
  - Foto secondaria (Galleria / Retro): input type="file" accept="image/*"

  Stato React:
    foto, fotoSecondaria          → File selezionati
    fotoPreview, fotoSecondariaPreview → anteprima (URL.createObjectURL)

  Al submit:
    await onSubmit(values, { copertina: foto, secondaria: fotoSecondaria });


B) Orchestrazione — admin/src/components/admin/AdminPanel.tsx
------------------------------------------------------------

  uploadFotoCopertina(veicoloId, file):
    FormData: foto, alt_text=file.name, is_copertina=true
    POST /api/veicoli/{veicoloId}/foto

  uploadFotoSecondaria(veicoloId, file, veicolo):
    Elimina foto secondarie esistenti (DELETE /api/veicoli/{id}/foto/{fotoId})
    FormData: foto, alt_text, is_copertina=false
    POST /api/veicoli/{veicoloId}/foto

  uploadPhotos() chiamato dopo creazione/modifica veicolo in handleCreate/handleUpdate


C) API — admin/src/app/api/veicoli/[id]/foto/route.ts
-------------------------------------------------------

  POST:
    1. requireAdmin() — verifica cookie sessione
    2. Legge formData: foto (File), alt_text, is_copertina
    3. Chiama uploadVeicoloFoto()
    4. Ritorna JSON con metadati foto (201)

  GET:
    Lista foto del veicolo (solo admin autenticato)

  DELETE (route separata [fotoId]):
    Rimuove file da Storage + riga da tabella foto


D) Servizio — admin/src/lib/services/veicoli.ts → uploadVeicoloFoto()
---------------------------------------------------------------------

  1. ensureStorageBucket() — verifica/crea bucket "veicoli"
  2. Genera path: {veicoloId}/{timestamp}-{uuid}.{ext}
  3. Upload buffer su Supabase Storage
  4. Ottiene URL pubblico
  5. Se is_copertina: rimuove flag da vecchie copertine del veicolo
  6. INSERT in tabella foto con metadati (alt_text, ordine, mime_type, peso_bytes)


E) Storage — admin/src/lib/supabase/storage.ts → ensureStorageBucket()
----------------------------------------------------------------------

  Verifica se bucket "veicoli" esiste.
  Se mancante, lo crea: pubblico, max 10 MB, solo image/jpeg|png|webp|gif


RIEPILOGO COMPORTAMENTO UPLOAD
------------------------------

  Formati accettati : jpeg, png, webp, gif
  Limite dimensione : 10 MB per file
  Path Storage      : {veicolo_id}/{timestamp}-{uuid}.{ext}
  Copertina         : is_copertina=true; una sola per veicolo
  Secondaria        : sostituisce eventuali foto non-copertina esistenti
  Sicurezza         : API protetta da cookie sessione admin
                      upload via service_role (non esposto al browser)
  Eliminazione      : DELETE /api/veicoli/{id}/foto/{fotoId}
                      rimuove file Storage + riga DB
